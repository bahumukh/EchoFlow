# Echoflow for Linux

> **Status: Under Construction**

This directory will contain the native Linux implementation of Echoflow, written in C++ (with GTK or Qt).

The Linux client will provide identical functionality to the macOS client:
- Global low-friction hold-to-talk dictation.
- Seamless text insertion into any active X11 or Wayland application.
- Uses the shared `whisper.cpp` engine bundled in the root `Vendor/` and `Runtime/` directories.
