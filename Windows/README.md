# Echoflow for Windows

> **Status: Under Construction**

This directory will contain the native Windows implementation of Echoflow, written in C# and .NET (WPF/WinUI).

The Windows client will provide identical functionality to the macOS client:
- Global low-friction hold-to-talk dictation.
- Seamless text insertion into any active Windows application.
- Uses the shared `whisper.cpp` engine bundled in the root `Vendor/` and `Runtime/` directories.
